* 概述

受 [[https://github.com/LuciusChen/ytm-radio/][ytm-radio]] 的启发，这是一款简单而多功能的音频播放器。

* 前提

** 需要的 Emacs 包
- [[https://github.com/d12frosted/vui.el][vui]]

** 安装
+ 克隆项目到你自己的 Emacs 配置目录下：
#+BEGIN_SRC sh
  git clone https://github.com/ginqi7/audio-player.el ~/.emacs.d/lisp/audio-player;
#+END_SRC

+ 把克隆的路径添加到 =load-path= 当中
#+BEGIN_SRC emacs-lisp
  (add-to-list 'load-path "~/.emacs.d/lisp/audio-player")
#+END_SRC

* 配置

#+BEGIN_SRC emacs-lisp
  (require 'audio-player)
  (require 'audio-player-mpv)
  (require 'audio-player-ui)
#+end_src
